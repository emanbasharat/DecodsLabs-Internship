# Expense Tracker 💰

A simple Python program that allows users to enter their expenses and calculates the total amount spent.

## 📌 Features

* Enter multiple expenses.
* Supports decimal expense amounts.
* Automatically calculates the total spending.
* Type `done` to finish entering expenses.
* Displays the total amount spent.

## 🛠️ Technologies Used

* Python

## ▶️ How to Run

1. Make sure Python is installed.
2. Open the project in Visual Studio Code.
3. Run the Python file.
4. Enter your expenses one by one.
5. Type `done` when you are finished.
6. The program will display your total spending.

## 💻 Example

```text
Enter your expense (or type 'done' to finish): 500
Enter your expense (or type 'done' to finish): 250.50
Enter your expense (or type 'done' to finish): 100
Enter your expense (or type 'done' to finish): done

Total Spent: 850.5
```
